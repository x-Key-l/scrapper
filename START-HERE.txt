SceneTrace 4.1 for Windows 10/11 x64

1. Right-click SceneTrace-Windows-x64.zip and choose Extract All.
2. Open the extracted SceneTrace folder.
3. Double-click SceneTrace.exe. Keep ALL included files together.

Browser: browse websites in tabs; use the toolbar menu to add or search a site.
Anime: search Pocket Monsters for official episode pages.
Quick Search: search Caminandes and choose Llamigos for direct playback.
Deep Search: describe a remembered scene, actor or character; refine the results.
Video Sources: Add Video Website, inspect and review a real test, then save.
History: delete one or several searches; use Undo for a recent deletion.
Downloads: ordinary website buttons work through the browser download dialog.
Videos button: inspect detected media, select a reported format and choose a folder.
Shield: view blocked requests, update rules or allow a site if playback breaks.
Media Library: import folders, edit series/episodes/categories, move or rename files.
New downloads use website folders by default; change this in Media Library.

The integrated browser uses the installed Microsoft WebView2 runtime. If missing,
SceneTrace opens your default browser and explains how to install the runtime.
No Python, Node, Git or Docker installation is needed.

Choose Quit SceneTrace before replacing or upgrading the portable folder.
Your profile remains in %LOCALAPPDATA%\SceneTrace.
See README.md and docs/HELP.md for help and verified source limitations.

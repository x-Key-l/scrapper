# SceneTrace 4.1 verification and compatibility

## Confirmed defects and repairs

The 4.0 native `DownloadStarting` handler canceled external downloads and sent their URLs to the analyzer. The 4.1 handler leaves the transfer running and preserves WebView2's download dialog. The analyzer is no longer a prerequisite for a website file. A separate all-permissions-denied handler also denied multiple automatic downloads; this now preserves WebView2's normal download permission decision.

Popup creation now attaches a real WebView2 child window, preserving `window.opener` and script-created `about:blank` pages. Closing a tab with an active transfer retains its hidden view until the transfer finishes. Existing destination filenames and in-flight destination names are reserved against accidental overwrite.

Media handling previously restricted container extensions and rejected some entries based only on metadata availability labels or missing license fields. Compatible HTTP files and yt-dlp native unencrypted HLS/DASH transports are now offered based on actual reported formats. Unsupported transports, actual DRM and source errors are explained individually. HTTP status codes survive the extraction proxy; certificate failures remain distinguishable. TLS validation is retained.

## Delivered implementation

- Unified native and analyzer transfer rows, real byte progress, speed/ETA when measurable, supported pause/resume/cancel, original-page retry, file/folder opening and independent history removal.
- Event-driven media observations from video/audio elements, compatible response MIME types, structured metadata and download links. Bounded scans and URL deduplication; no private headers or response bodies are collected. A detector result is not proof that an extractor can download it.
- SQLite Media Library, import without moving files, source folders, conservative episode parsing, indexed alternative-title matching, manual categories/collections, bulk edit, rename and collision-safe moves. Uncertain matches remain suggestions.
- HaGeZi Light domain filtering with per-site/global controls, safe manual update and cache, limited cosmetic cleanup, popup classification and media/navigation exemptions. Full Adblock Plus syntax and Chromium extensions are not implemented.
- Compact dark native tabs above the address toolbar, responsive address width, original styling and system fonts. WebView2 remains the browser engine.

## Test evidence

The local Python suite currently has **105 passing tests**. Actual FFmpeg-generated media is transferred and decoded in HTTP, HLS, DASH, conversion and separate-track cases. These are controlled transport tests, not proof of a specific commercial website's compatibility.

Check their individual results; a provider response is not an all-capabilities verification.

## Performance and acceptance scope

The 4.0 Windows CI baseline was 9.071 s cold and 1.394 s warm native app readiness; host plus shared WebView2 RSS was approximately 335 MiB idle, 434/416 MiB with one website, and 500/482 MiB with five website tabs (four inactive). These are shared-runner observations, not older-PC guarantees.

The 4.1 ZIP includes fresh cold/warm process-tree measurements and filtering CPU time. Library indexing measures 1,000 small filesystem fixtures and SQLite metadata work, not video decoding. Local Linux timing was 0.960 s initial indexing and 0.280 s unchanged reindex. Compare platforms and workload before drawing performance conclusions.

Physical 125%/150% display scaling, interactive Save As acceptance, long transfers, sleep/wake, antivirus prompts and older-laptop CPU/playback measurements still need owner-side testing. Current automated layout checks cover 1366×768 and 1920×1080 client sizes. Browser-native downloads interrupted by application exit cannot be resumed through a lost WebView2 operation; reopen the source and restart. Adaptive stream resumption and available formats depend on the extractor and source.

No universal website compatibility or unrestricted access to protected media is claimed. Ordinary website transfers remain usable when analysis fails.
